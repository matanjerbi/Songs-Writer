# שורה — מחברת שירים חכמה

אפליקציית אנדרואיד לכתיבת שירים בעברית.

## הורדה
את ה-APK האחרון מורידים מ-[Releases](../../releases/latest) — כל דחיפה ל-main בונה גרסה חדשה אוטומטית.

## מה יש בה
- עורך שירים מימין לשמאל, שמירה אוטומטית, ביטול/חזרה, מצב פוקוס
- **מחפש חרוזים** עברי שעובד בלי אינטרנט (~23 אלף מילים, ממוינות לפי שכיחות)
- **ניתוח שיר** — תבנית חריזה לכל בית בצבעים, מילים שחוזרות, מספר מילים לשורה
- **עוזר AI (Claude)** — המשך שורות, ניסוח מחדש, ביקורת, דימויים, "תקוע לי", כותרות, חרוזים בהקשר, בקשה חופשית (דורש מפתח API בהגדרות)
- **השראה** — נושא, מילה, פתיחה, אילוץ ותמונה אקראיים, והשראה יומית
- תגיות, מועדפים, חיפוש, גרסאות קודמות לכל שיר, שיתוף, גיבוי/שחזור לקובץ
- שלושה מצבי תצוגה (נייר/לבן/לילה) ושלושה גופנים

## מבנה
אפליקציה מקומית (HTML/JS ב-`app/src/main/assets/www`) בתוך WebView של אנדרואיד.
מילון: Hspell (GPL) × רשימת שכיחות FrequencyWords (CC-BY-SA).
